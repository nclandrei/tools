Turn a Git LFS pointer into the real file. Paste a public GitHub URL (blob, raw, or media) and the tool rewrites it to GitHub's media host, fetches the actual object, and hands you the binary. You can also drop or paste a pointer file to inspect its oid and size.

How it works. GitHub-hosted LFS objects are available at media.githubusercontent.com/media/{owner}/{repo}/{ref}/{path} — the same URL the web "Download" button uses. This tool rewrites any github.com/.../blob/... or raw.githubusercontent.com/... URL to that media URL and fetches it.
  • Public repos only. Private repos need auth and won't work from a browser.
  • GitHub only. GitLab, Bitbucket, and self-hosted LFS endpoints don't allow cross-origin fetches.
  • If CORS ever blocks the fetch, the result box shows a direct download link you can open in a new tab.
  • Pointer files alone aren't enough to download — the oid needs an LFS server. If you only have the pointer, also paste the GitHub blob URL above.
